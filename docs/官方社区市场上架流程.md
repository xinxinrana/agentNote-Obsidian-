## 三、阶段 1：完成仓库和合规准备

### 1.1 补充许可证

**负责人：我处理完成。**

### 1.2 检查 manifest

**负责人：我主导。**

逐项确认 `manifest.json`：

- `id` 使用小写字母和连字符，当前为 `agentnote`。
- `name` 使用简短、可识别的名称，不能包含 `Obsidian` 或 `Plugin` 等受限名称。
- `version` 使用严格的 `x.y.z` 格式，并与 Release Tag 一致。
- `minAppVersion` 与实际兼容版本一致。
- `description` 不超过 250 个字符，以英文句号结尾，不使用 emoji 或不必要的特殊字符。
- 使用 Node.js、Electron、本地文件系统和本地 HTTP 服务，因此保留 `isDesktopOnly: true`。
- 不接受赞助时不添加 `fundingUrl`。
- `authorUrl`、仓库地址和作者信息保持一致。

当前已处理：`description` 已改为简短的英文动作描述，以英文句号结尾，长度符合官方限制；README 已改为英文主文档，并保留中文功能说明跳转。

官方参考：

- [Submission requirements for plugins](https://docs.obsidian.md/community-directory/submission-requirements-for-plugins)
- [Manifest reference](https://docs.obsidian.md/Reference/Manifest)
