# 小笺使用场景

这三张图用于介绍 agentNote 的核心流程，属于概念插画，不是插件界面截图。图片为 1536 × 1024 PNG，可用于仓库介绍、文档和演示材料。正式界面操作以插件截图为准。

## 1. 分享本地资料

![小笺陪用户从本地笔记中分享资料](01-share-local-note.png)

在本地笔记中选中一份资料，生成交给 agent 使用的分享地址。

## 2. Agent 读取分享内容

![小笺引导 agent 读取分享的资料](02-agent-reads-note.png)

Agent 通过分享地址获取资料的当前内容和上下文。

## 3. 成果写回笔记库

![小笺把新笔记放回本地资料库](03-write-back-to-vault.png)

Agent 的成果成为本地笔记，之后仍可整理和复用。

## 生成提示词

以下场景都以 [`xiaojian-idle.png`](../png/xiaojian-idle.png) 作为角色参考，使用图像生成工具制作。统一要求：保留折角笔记的轮廓、紫色描边、椭圆眼睛和粉色脸颊；浅紫与米白的柔和二维插画；横向画面；无可读文字、Logo、水印或圆形头像。

1. **分享资料**：一位用户在安静的桌面上，从本地笔记界面选中一份资料并分享；小笺站在笔记本电脑旁，指向选中的资料和流向 agent 的连接。
2. **读取内容**：笔记本电脑中的本地资料经分享连接到另一块显示屏；小笺在前景引导，显示屏只展示抽象的矩形阅读工作区与文档线条。
3. **写回笔记库**：小笺把新文档放入电脑里的本地笔记卡片列表，一位用户看到新增的资料；画面表达成果已保存且可复用。
