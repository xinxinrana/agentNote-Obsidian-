# agentNote 视觉识别规范

agentNote 让本地笔记与文件顺畅进入 agent 工作流。视觉语言以“可读的纸张”为核心：清晰、轻量、亲近。小笺是折角笔记形象，标志与角色均保留折角、紫色轮廓和深紫表情。

## 标志与角色

| 场景 | 使用文件 | 规则 |
| --- | --- | --- |
| 横向页眉、封面、介绍图 | [品牌组合](agentnote-lockup.svg) | 保持完整字标与标记，最小宽度 180 px。 |
| 小尺寸入口、方形图标 | [笔记标记](xiaojian-mark.svg) | 保持方形画布，最小宽度 24 px。 |
| 接入台、常规介绍 | [小笺常态](xiaojian-idle.svg) | 完整展示，最小宽度 72 px。 |
| 欢迎、分享成果 | [小笺挥手](xiaojian-wave.svg) | 完整展示，最小宽度 72 px。 |
| 思考、提示 | [小笺思考](xiaojian-thinking.svg) | 完整展示，最小宽度 72 px。 |

所有文件以 SVG 为主文件；同名透明 PNG 位于 [`png/`](png/)。四周至少保留标记宽度 **1/4** 的空白。保持原始宽高比和图形颜色，避免裁掉折角、四肢或表情。圆形裁切不属于这套形象。

## 色彩

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| 品牌紫 | `#8652CF` | 标记轮廓、重点操作、品牌强调 |
| 深紫 | `#392552` | 字标、标题、角色表情和正文深色 |
| 折角浅紫 | `#D8B5FF` | 折角与柔和点缀 |
| 纸张浅色 | `#F8F3FF` | 标记填充、浅色卡片 |
| 腮红粉 | `#F7A5C8` | 角色面部细节；不用于正文 |
| 白色 | `#FFFFFF` | 主背景与留白 |

在浅色背景上使用深紫正文和品牌紫重点。深色界面中将完整角色放在可区分轮廓的浅色卡片上；正文和操作按钮仍遵循宿主界面的可访问性色彩。不要将浅紫或粉色用作小字号文字。

## 字体与排版

- 品牌组合使用现成的 [SVG 字标](agentnote-lockup.svg)，不要重新排写字母或改变大小写。
- 正文和界面采用系统无衬线字体，中文优先系统中文字体。可直接使用 [`tokens.css`](tokens.css) 中的字体栈。
- 标题建议 700 字重；正文 400–500 字重，行高约 1.5。短标签可用 700 字重，不使用过宽的字距。
- 内容采用左对齐；角色与文案并排时，将角色放在文案前，避免覆盖正文。

## 界面与动效

- 卡片圆角 12–16 px，间距按 4 px 的倍数递增。保持角色周围清爽，让内容和操作始终优先。
- 接入台使用常态角色；知识贡献分享图使用挥手角色；说明或等待状态可使用思考角色。
- 角色可做 4 秒左右、上下不超过 4 px 的轻微浮动。遵循 `prefers-reduced-motion`，启用后保持静态。
- 所有角色图片提供“小笺”相关替代文本；纯装饰性重复图片可设为空替代文本。

## 可复用文件

下载或复制 [`README.md`](README.md) 列出的 SVG / PNG。品牌颜色与字体变量见 [`tokens.css`](tokens.css)；桌面插件中的角色直接引用这组 SVG。
